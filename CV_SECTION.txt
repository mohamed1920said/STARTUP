CV SECTION — LoRa Star Network IoT System
===========================================

LoRa Star Network — IoT Gateway & Sensor/Actuator Nodes
(PlatformIO, ESP32, LoRa SX1276, AES-128-GCM, MQTT, WebDashboard)

Designed and built a production-grade, low-power LoRa star network operating
at 868 MHz consisting of a central gateway, sensor node, and actuator node.

- Developed firmware for three ESP32-based nodes (gateway, sensor, actuator)
  using PlatformIO with conditional compilation for TTGO LoRa32 v2.1 and
  ESP32-S3 hardware variants.
- Implemented AES-128-GCM encryption with 12-byte random nonce and 4-byte
  truncated MIC for secure wireless communication over LoRa.
- Built a web-based dashboard served from the gateway's LittleFS filesystem
  with real-time telemetry via WebSocket, node provisioning via NVS, and
  REST API for data queries.
- Integrated MQTT broker (PicoMQTT) on the gateway for MQTT client access.
- Wired and calibrated capacitive moisture sensor, DS18B20 temperature
  sensor, and battery voltage monitor on the sensor node.
- Implemented CAD (Channel Activity Detection) + listen mode on the
  actuator node for low-power downlink reception and valve control with
  feedback monitoring.
- Created a RadioLib-compatible wrapper (LoraRadio) around the Arduino LoRa
  library to resolve SX1276 receive issues on TTGO hardware.
- Debugged and fixed a critical authentication tag length mismatch in
  mbedtls GCM decrypt that was causing all received packets to be rejected.
